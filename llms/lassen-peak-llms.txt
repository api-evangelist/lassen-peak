# Lassen Peak

> Lassen Peak, Inc. is a Seattle-area public-safety technology company (founded 2019) that builds
> AirFrisk, a handheld terahertz imaging-radar scanner for detecting concealed weapons without a
> hands-on pat-down, and ImageVault, the FBI-CJIS-compliant cloud console that manages AirFrisk
> users, devices, scan data, retention policy, alerts, reporting and audit logs for an agency.

## Agent-relevant summary

- Lassen Peak publishes **no public API**. As of 2026-08-23 there is no developer portal, no API
  reference, no OpenAPI/AsyncAPI/GraphQL/Postman artifact, no SDK in any public package registry,
  no public GitHub organization, and no `/.well-known/` discovery surface on any host it controls.
- Products are sold direct to police, sheriff and security agencies. There is no self-serve signup,
  no published pricing, and no documented rate limits.
- Customer training and user guides (AirFrisk, ImageVault User/Supervisor, ImageVault Administrator)
  sit behind a TalentLMS tenant login at https://lassenpeak.talentlms.com/plus/login and are not
  API documentation.
- The only machine-readable surface on the domain is the default WordPress REST API at
  https://www.lassenpeak.com/wp-json/ — the marketing site's CMS, not a Lassen Peak product API.
  It is recorded here for accuracy and is deliberately NOT profiled as a company API.

## Products

- [AirFrisk](https://www.lassenpeak.com/airfrisk/): handheld terahertz imaging-radar concealed
  weapon detection scanner; ~1 mW radiated power, non-ionizing, ~12h battery target, material
  agnostic (plastic, polymer, wood, metal), on-screen overlay of detected object location.
- [ImageVault](https://www.lassenpeak.com/imagevault/): cloud management for AirFrisk users,
  devices and scan data — FBI-CJIS compliant storage, historical scan review, configurable
  agency fields and retention policy, alerts, role management, pre-configured reporting, and
  audit logs of all user activity.
- [Public Safety](https://www.lassenpeak.com/public-safety/): the agency-facing solution page.
